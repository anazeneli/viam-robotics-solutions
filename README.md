# viam-robotics-solutions
A modular system to explore Viam Robotics' API, featuring solutions for webcam object detection, cloud integration, and custom module registration. The project emphasizes reproducibility, scalability, and explainability, testing the platform's flexibility and capabilities across various use cases.

## API Key 
Create a .env file to manage API information for the following values: 

ROBOT_API_KEY

ROBOT_API_KEY_ID

ROBOT_ADDRESS

ML_MODEL_NAME (optional for exploration)

VISION_NAME

CAMERA_NAME
